多指连点器
多指连点器是一款无障碍辅助工具，专为有需要的用户提供触摸模拟与重复操作自动化功能。 【主要功能】 ✅ 辅助行动不便用户进行触屏操作 ✅ 协助进行应用功能测试和演示 ✅ 支持自定义点击位置、频率和时长 ✅ 可保存多个操作配置方案 【无障碍权限说明】 本应用使用 AccessibilityService API 仅用于： • 在用户指定位置执行点击操作 • 模拟触摸手势以辅助操作 • 不会在未经您操作的情况下读取密码、短信等敏感内容 • 不会将无障碍权限用于监控其他应用界面内容 【权限控制】 您可以随时在 设置 > 无障碍功能 中禁用本应用的权限。 禁用后，应用将停止所有触摸模拟功能。 【数据与隐私】 您的连点方案与任务配置保存在本地设备中。应用提供免费版与会员订阅（应用内购买）；免费版可能展示第三方广告。部分功能（如广告、统计、版本更新、会员服务等）需要联网，我们可能按隐私政策收集并使用相关设备与使用信息。 查看完整隐私政策 适用于需要触摸辅助的用户，请合理合法使用。
